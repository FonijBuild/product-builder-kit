## Included

```text
idea/          Problem and opportunity framing
validation/    Assumptions and validation plans
product/       PRD, MVP scope, stories, acceptance criteria
design/        Design briefs and UX decisions
engineering/   Architecture, ADRs, and implementation plans
agents/        Context and working agreements for coding agents
```

## Use it when

- Turning an early idea into an MVP
- Preparing a project before code generation
- Writing implementation-ready feature specs
- Handing work to an AI coding agent
- Recording decisions that should survive chat history

## Working rule

Keep documents short, decision-oriented, and current. Delete stale assumptions instead of accumulating process for its own sake.

Fonij may generate or update these artifacts automatically, but the files remain understandable without the CLI.
